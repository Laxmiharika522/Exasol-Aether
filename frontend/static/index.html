Exasol Database Engine

Aether is natively connected to a local instance of Exasol Personal (Nano) running on Docker.

⚡
In-Memory Engine: Exasol processes complex analytics datasets completely in-memory, providing sub-second analytical query performance.
📊
Columnar Storage: Organizes data by columns instead of rows, drastically reducing disk/RAM read times during heavy aggregation queries (e.g. SUM, AVG, JOIN).
🧠
AI & UDF Integration: Natively runs User-Defined Functions in Python/R/Java and supports Model Context Protocol (MCP) to bring LLM logic directly to data.
⚙️
Auto-Tuning: Eliminates manual DBA tuning. Automatically optimizes query plans, column indexes, and data distribution across clusters.
